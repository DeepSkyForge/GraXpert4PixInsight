# GraXpert Process Discontinued

The GraXpert process for PixInsight has been withdrawn to comply with PixInsight's [Certified PixInsight Developer Program Rules](https://pixinsight.com/security/cpd-rules/) version 1.0.2, specifically Rule 5.5, which prohibits signed code from running components of other image-processing or astrophotography applications within PixInsight, regardless of the mechanism used.

Although the GraXpert Development Team had granted permission to use its software components, this rule also applies to C++ ports of external application components.

I would like to thank the GraXpert Development Team for their cooperation and support, as well as everyone who has shown interest in this integration.

Thank you for your understanding.
